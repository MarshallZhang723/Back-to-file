# 个人记账工具 - 项目规划

## 项目概述
一个极简的个人记账 Web 应用，聚焦快速记录和消费洞察。

## 产品形态
Web 应用，响应式设计，支持桌面和移动端浏览器访问。

## 核心功能
1. 极速记账 — 30 秒内完成一笔记录（金额 + 分类）
2. 月度报表 — 自动按分类生成消费报表
3. 消费趋势 — 月度/季度支出趋势图

## 页面结构
- 首页：快速记账入口 + 本月概览
- 记录页：记账表单 + 分类选择
- 报表页：月度报表 + 趋势图

## 技术栈
- 前端：React + TailwindCSS + Recharts
- 存储：localStorage（MVP）/ IndexedDB（后续）
- 部署：Vercel / GitHub Pages

## 设计规范
极简中性风格，以数据为核心。
