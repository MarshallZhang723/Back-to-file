# DataModel.md 模板 — 数据模型

## 模板

```markdown
# [项目名称] - 数据模型

## 实体定义
### [实体名称]
- **字段**：字段名 / 类型 / 约束（如 NOT NULL、UNIQUE、DEFAULT）
- **主键**：<!-- 主键字段 -->
- **索引**：<!-- 索引字段列表 -->
- **约束**：<!-- 字段级业务约束，如 金额 > 0、状态 ∈ {active, archived} -->
- **关系**：
  - belongs_to：[关联实体]
  - has_many：[关联实体]

## 关系图（文字描述）
<!-- 实体间的一对多、多对多关系 -->

## 数据流说明
<!-- 核心数据的生命周期和流转路径 -->

## 业务规则
<!-- 跨实体的业务约束和操作规则 -->
- **[规则 1]**：<!-- 如：删除分类前需确认该分类下无关联交易 -->
- **[规则 2]**：<!-- 如：预算金额不可超过设定的收入上限 -->
```

## 对齐校验：DataModel.md → Plan.md

- 实体定义是否覆盖了 Plan.md 核心功能所需的数据？
- 数据模型复杂度是否与项目规模匹配（如简单的记账应用不需要多租户设计）？

## 后续约束

- API 设计必须严格对齐 DataModel.md 中的实体和关系定义
- 业务逻辑实现必须严格对齐 DataModel.md 中的 Schema 定义
