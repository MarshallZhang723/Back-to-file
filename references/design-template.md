# Design.md 模板 — 设计系统规范

从前三步（信息布局排版 → 视觉色彩搭配 → 交互动效）的产出反向提炼。

## 模板

```markdown
# [项目名称] - 设计系统规范

## 设计 Tokens
- **色彩**：主色、辅色、中性色、语义色（成功/警告/错误），附色值
- **字体**：字族、字号层级、行高、字重
- **间距**：间距刻度（4px 基准）、内边距/外边距规则
- **阴影**：层级（卡片/下拉/弹窗）
- **圆角**：刻度（小/中/大/全圆）
- **动画**：缓动函数、持续时间

## 组件库
- **基础组件**：Button、Input、Select、Card、Modal、Tag、Toast 等
- **每个组件**：用途说明、样式属性、交互状态（hover/active/disabled）、尺寸变体

## 布局规范
- 页面网格、断点、响应式规则
- 内容区域最大宽度、边距

## 图标与资源
- 图标风格、来源（如 lucide-react 等）
```

## 对齐校验：Design.md → 前三步产出

- Design.md 中的所有色彩值是否能在视觉色彩搭配中找到对应使用？
- 组件定义是否准确反映了前三步中实际使用的组件样式和变体？
- 间距、圆角、阴影刻度是否严格对应信息布局排版中的实际值？
- 动画 tokens 是否与交互动效中使用的 GSAP 缓动和持续时间一致？
- 是否有前三步中未使用的设计元素被错误地添加？

如发现与前三步产出不一致，以实际代码为准更新 Design.md（记录 Change.md）。
