# Concept.md 模板 — 概念定义

```markdown
# [项目名称] - 概念定义

## 动机
<!-- 为什么想做这个项目 -->

## 要解决的问题
<!-- 具体要解决什么问题 -->

## 解决方案
<!-- 打算用什么方式解决 -->

## 方案理由
<!-- 为什么选择这个方案 -->

## 竞品/现有方案分析
<!-- 已有方案及其不足 -->

## 深层洞察
<!-- 对需求的深入思考 -->

## 待定信息
<!-- 以下内容在概念阶段暂不确定，将在项目规划阶段进一步明确 -->
- **产品形态**：Web 应用 / 移动端 / CLI / 库？
- **技术方向**：前后端框架倾向？
- **界面预期**：是否需要用户界面？有多少个主要页面？
```
