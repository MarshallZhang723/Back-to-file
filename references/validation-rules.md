# 校验规则（Validation Rules）

## 阶段间对齐校验

### Plan.md → Concept.md
- **问题覆盖**：Concept.md 中每个"要解决的问题"在 Plan.md 中是否有对应的功能或方案？
- **洞察体现**：Concept.md 中的"深层洞察"是否在 Plan.md 的设计思考中得到回应？
- **方案一致**：Concept.md 的"方案理由"与 Plan.md 的技术选型是否吻合？
- **待定信息**：Concept.md 中的"待定信息"是否已在 Plan.md 中得到确认和明确？

### Project.md → Plan.md
- **功能覆盖**：Plan.md 中的每个"核心功能"在 Project.md 中是否有对应的任务或阶段？
- **技术栈一致**：Project.md 的技术选型是否与 Plan.md 保持一致？
- **产品形态匹配**：Project.md 的阶段划分是否符合 Plan.md 定义的产品形态？（如 CLI 工具不应有前端阶段）

### Task.md → Project.md
- **任务一致**：Task.md 中的任务列表是否与 Project.md 的阶段划分和任务定义一致？
- **依赖满足**：是否有任务的前置依赖还未就绪？
- **阶段状态**：各阶段的状态标记是否正确反映当前进展？

### 信息布局排版 → Plan.md
- 布局和页面结构是否与 Plan.md 中的页面/界面结构一致？
- 技术选型是否与 Plan.md 一致？

### 视觉色彩搭配 → 信息布局排版
- 色彩和视觉风格的添加是否改变了上一步确定的布局结构和层级？
- 色彩是否增强了信息层级而非干扰？

### 交互动效 → 信息布局排版 + 视觉色彩搭配
- 动效是否改变了前两步确定的布局结构和色彩关系？
- 入场动画在 JS 未加载或无动效状态下是否仍可见？

### Design.md → 前三步产出
- 所有色彩值是否能在视觉色彩搭配中找到对应使用？
- 组件定义是否准确反映了前三步中实际使用的组件样式和变体？
- 间距、圆角、阴影刻度是否严格对应信息布局排版中的实际值？
- 动画 tokens 是否与交互动效中使用的 GSAP 缓动和持续时间一致？

### 业务逻辑 → DataModel.md + API.md
- 数据读写是否与 DataModel.md 中的字段和约束一致？
- 暴露的端点是否与 API.md 的定义完全匹配？
- 返回的数据结构是否与 API.md 一致？
- 业务校验逻辑是否与 DataModel.md 中的约束和业务规则一致？

### 交互实现 → Design.md + API.md
- UI 组件和样式是否仍与 Design.md 保持一致（如有新增组件，先在 Design.md 补充定义）？
- API 调用是否与 API.md 中的端点定义一致？

## 5.1.1 信息布局排版 — 预检清单

- [ ] 设计解读已声明
- [ ] 旋钮值与需求匹配
- [ ] 无三张等宽功能卡并列
- [ ] 无 em-dash（`—`）
- [ ] 无 h-screen（使用 min-h-[100dvh]）
- [ ] Hero 首屏完整可见，CTA 无需滚动
- [ ] CTA 按钮文字在桌面端不换行
- [ ] Hero 文本元素 ≤ 4 个（eyebrow/标题/副文本/CTA）
- [ ] 导航单行显示，高度 ≤ 80px
- [ ] 正文字宽限制在 65-75ch
- [ ] 展示标题 clamp 上限 ≤ 6rem
- [ ] 响应式检查：768px 断点布局正常
- [ ] Z-index 有层次管理，不随意使用 z-50
- [ ] 布局间距有节奏变化，非等距重复

## 5.1.2 视觉色彩搭配 — 预检清单

- [ ] 无 AI 默认色（紫/蓝渐变）
- [ ] 全页色彩一致性锁定（仅用一种强调色）
- [ ] 全页圆角体系一致性锁定
- [ ] 正文对比度 >= 4.5:1
- [ ] 强调色饱和度 < 80%
- [ ] 无暖中性背景色（cream/sand/beige）作为默认
- [ ] CTA 无重复意图（同一页面不同位置的 CTA 文案一致）
- [ ] 链接文本独立可理解（"View pricing plans" 优于 "Click here"）
- [ ] 禁止侧条纹边框、渐变文字、毛玻璃默认装饰
- [ ] 无 hero-metric template（大数字/小标签/统计数据的 SaaS 陈词滥调）
- [ ] 无编号的 section 标记（01/02/03）
- [ ] 每个 section 上方无小号全大写 eyebrow（如非品牌必要）

## 5.1.3 交互动效 — 预检清单

- [ ] 动效只驱动 transform 和 opacity
- [ ] 动效尊重 `prefers-reduced-motion`
- [ ] 无 `window.addEventListener('scroll')`
- [ ] 缓动使用指数曲线（power2.out / power3.out），无弹跳
- [ ] 入场动画不依赖类触发的过渡（增强默认状态）
- [ ] 滚动触发动画使用 ScrollTrigger 而非手动 scroll 事件
- [ ] 动效 60fps 流畅
- [ ] React 项目使用了 useGSAP hook 和 context 自动清理
