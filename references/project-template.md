# Project.md 模板 — 实施计划

根据 Plan.md 产品形态调整阶段划分：
- **Web 应用**：前端骨架 → 后端 → 前端交互集成 → 部署
- **CLI 工具**：后端 → 部署
- **静态网站**：前端骨架 → 部署

```markdown
# [项目名称] - 实施计划

## 阶段总览

本项目按 [产品形态对应阶段] 执行。

## 阶段详情

### 阶段一：[阶段名称]
- **任务列表**：
  - [ ] 任务 1
  - [ ] 任务 2
- **交付结果**：<!-- 该阶段完成后交付什么 -->
- **验收标准**：<!-- 如何验证交付物达标 -->

### 阶段二：[阶段名称]
<!-- 同上 -->
```

## 规则

- 每个阶段是逻辑自洽的工作单元，可独立交付和验收
- 任务粒度：一个任务应在 1-3 天内完成
- 阶段间有依赖关系时需明确标注
- **状态管理**：每完成一个阶段，将 `[ ]` 更新为 `[x]`，标注完成日期

## 简化规则

对于落地页/品牌官网等简单前端项目（页面少、无复杂交互、无复用组件），可直接省略 Design.md 反向提炼步骤，前三个子步骤的产出即为最终设计参考。
