# Task.md 模板 — 任务跟踪

```markdown
# [项目名称] - 任务跟踪

## 阶段一：[阶段名称]

### 任务 1：[任务名称] ✅ 已完成
#### 实施日志
- [2024-01-01] 做了什么，结果如何
- [2024-01-02] 遇到了什么问题，如何解决

### 任务 2：[任务名称] 🔄 进行中
#### 实施日志
- [2024-01-03] 开始实施，当前进展

### 任务 N：[任务名称] ⬜ 未开始
#### 实施日志
<!-- 暂无 -->

## 阶段二：[阶段名称]
<!-- 同上 -->
```

## 状态规则

- 任务状态分三种：⬜ 未开始 / 🔄 进行中 / ✅ 已完成
- 每个任务应是可独立验证的单元
- 当某个阶段所有任务验收通过后：
  1. 回到 **Project.md** 更新对应阶段完成状态（`[ ]` → `[x]`），标注完成日期
  2. 读取 **Project.md** 确认下一阶段任务列表
- 每次有进展时在 Task.md 中追加日志，而不是覆盖
